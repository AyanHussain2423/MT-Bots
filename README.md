# Trader Knowledge

A persistent, compounding trading wiki (Karpathy's "LLM Wiki" pattern) for
Zaid's MT5/XM gold trading bots and strategy research.

- **`raw/`** — immutable source documents: trade dumps, CSV exports, logs.
- **`wiki/`** — the living knowledge base: sources, entities, concepts,
  synthesis. Every trade is ingested and linted here.
- **`AGENTS.md`** — the schema the agent follows.

Start at [`wiki/index.md`](wiki/index.md).
