# raw/ — Immutable Sources

Read-only layer. Never edit or delete anything here. This is the source of
truth; the wiki cites back to it.

- **`trades/`** — one CSV/dump per trading session (e.g.
  `2026-09-08-real-account.csv` from the MT5 `HistoryDump_Zaid` script).
- **`strategy/`** — strategy source documents (AMN guides, bot specs, etc.).

External sources (YouTube, Scribd, websites) are cited by URL in the wiki
pages rather than mirrored here.
